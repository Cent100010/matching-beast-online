マッチングビースト オンライン版（初期プロトタイプ）

■ この版でできること
・ホストを含む人間1〜4人で対戦（空席はCPUに置き換え）
・部屋番号で参加
・CPUとの1人プレイを継続
・元HTMLのゲーム処理をベースに、ドロー、召喚、攻撃、特殊ビースト、CPU思考設定などを維持
・各プレイヤーの手札は本人以外にカード内容を送らず、相手側には裏向きカードの枚数のみ表示

■ ローカル起動（Windows / PowerShell）
1. Node.js が入っていることを確認します。
2. このフォルダーを VS Code で開きます。
3. ターミナルで次を実行します。
   npm.cmd install
   npm.cmd start
4. ブラウザーで http://localhost:3000 を開きます。
5. 別のブラウザー／端末から同じPC内の対戦を試す場合は、PCのローカルIPアドレスを使って http://PCのIPアドレス:3000 にアクセスします。ファイアウォール設定が必要な場合があります。

■ 遊び方
・ホストが「部屋を作る」を押します。
・表示された5文字の部屋番号を対戦相手に共有します。
・相手はプレイヤー名と部屋番号を入力して「部屋に参加」を押します。
・ホストが「対戦開始（空席はCPU）」を押すと開始します。参加していない席はCPUになります。
・ホストが1人だけで開始すれば、CPU3人との1人プレイです。
・CPUの思考傾向、初期HP、特殊枠の設定はホスト側の設定が使用されます。

■ GitHub / Render へ配置
・このフォルダーの中身をGitHubリポジトリに push します。
・Render では Web Service としてリポジトリを接続します。
・Build Command: npm install
・Start Command: npm start
・Node環境が選ばれていることを確認します。
・デプロイ後のURLを各プレイヤーが開き、部屋番号で参加します。

■ 大事な注意
・これはオンライン化の初期版です。まずローカルで2ブラウザーを使い、部屋作成、参加、手札秘匿、通常召喚、特殊召喚、攻撃、CPU補充を確認してください。
・ホストのブラウザーが対戦処理を実行する方式です。ホストが切断すると部屋は終了します。
・Render等へ公開する場合は、プレイテスト前の試作URLとして扱ってください。
